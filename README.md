# Docker basics

Лабораторная работа по запуску статической страницы в Docker-контейнере с Nginx и HTTPS.

## Состав проекта

- `Dockerfile` собирает образ на базе `nginx:alpine`.
- `default.conf` настраивает Nginx на работу по HTTPS на порту `443`.
- `index.html` содержит тестовую страницу.
- `run_lab.sh` создаёт самоподписанный сертификат, собирает образ и запускает контейнер.
- `renew-cert.sh` вручную пересоздаёт сертификат и перезагружает Nginx в уже запущенном контейнере.

## Запуск

```bash
./run_lab.sh
```

Скрипт создаёт папку `certs`, проверяет наличие файла `certs/nginx.crt`, собирает образ `lab06_docker:latest` и запускает контейнер `lab-docker-basic`.

Если сертификата ещё нет, `run_lab.sh` создаёт самоподписанный сертификат и приватный ключ:

```text
certs/nginx.crt
certs/nginx.key
```

Если `certs/nginx.crt` уже существует, сертификат повторно не создаётся.

После запуска страница доступна по адресу:

```text
https://localhost:54321
```

Так как сертификат самоподписанный, браузер покажет предупреждение безопасности. Для проверки через терминал можно использовать `-k`:

```bash
curl -k https://localhost:54321
```

## Обновление сертификата

Для пересоздания сертификата без пересборки образа:

```bash
./renew-cert.sh
```

Контейнер `lab-docker-basic` должен быть запущен.

После обновления скрипт проверяет конфигурацию Nginx, перезагружает его внутри контейнера и показывает срок действия нового сертификата.

## Остановка и удаление контейнера

```bash
docker rm -f lab-docker-basic
```
